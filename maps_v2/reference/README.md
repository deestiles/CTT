# Reference map images

Drop a top-down map screenshot here (PNG or JPG) to import it in the builder,
e.g. `maps_v2/reference/map.png`. In the builder's "Map image" field use either:

- `res://maps_v2/reference/map.png`, or
- the full path, e.g. `C:\Projects\Catch the Thief\catch-the-thief-mapbuilder\maps_v2\reference\map.png`
